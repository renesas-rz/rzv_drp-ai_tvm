## Tasks included in the model list   

The following tasks are listed in the model list, along with their inference time. Refer to each device’s model list for details.   

- Object Detection
- Classification
- Pose Estimation
- Multi Person Pose Estimation
- Semantic Segmentation
- Instance Segmentation
- Face Recognition
- Face Landmark Detection
- Hand Landmark Detection
- Depth Estimation
- Text Detection
- Text Recognition

 **NOTE** : The set of tasks included in the model list differs across devices.
