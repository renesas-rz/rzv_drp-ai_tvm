# Compilation example without subgraph partitioning   
:information_source: **[NOTE]** This feature is currently in beta version.   

## What is `compilation without subgraph partitioning`   
In RUHMI[^1], the input model is analyzed, and subgraphs are generated by assigning layers to both DRP-AI and the CPU. The performance of DRP-AI is maximized when all operations are assigned to a single DRP-AI subgraph.
This folder contains compilation example scripts that perform compilation without subgraph partitioning. This sample script attempts to assign all layers of the target ONNX model to DRP-AI to maximize performance.   

:warning: **Note:** Compilation will fail if the model contains operators unsupported by DRP-AI. In that case, please use the standard compilation script in the [tutorial folder](../tutorials/). Please refer to the [DRP-AI Translator i8 User's Manual](https://www.renesas.com/ja/software-tool/drp-ai-translator-i8) for the list of supported operators.  


## How to use
### 1. Copy scripts from tutorial directory
Please copy the base compilation scripts from the tutorial folder:   
```sh
cd ${TVM_ROOT}/how-to/no_partition_sample/
cp -r ${TVM_ROOT}/tutorials/drpai_preprocess ./.
cp ${TVM_ROOT}/tutorials/arg_parser.py ./.
```

### 2. Compile ONNX model
The compilation method is the same as the standard compilation. An example of the compilation procedure is shown below.
```sh
cd ${TVM_ROOT}/how-to/no_partition_sample/
python3 compile_onnx_quant_wo_partitioning.py \
  TARGET_ONNX.onnx \
  -o TARGET_ONNX \
  -t $SDK -d $TRANSLATOR -c $QUANTIZER
```
After the compilation completes successfully, the runtime object files are generated in the output folder specified by the `-o` option.   
Please refer to the [how-to sample app guide for V2H](../sample_app_v2h) for instructions on how to change calibration settings and PreProcess settings for each model.

## Supported Input & Output Shape
Currently, this script supports only V2H/N and ONNX model inputs. The supported input and output shapes are listed below.
| # of Inputs | Input shape | # of Outputs | Output shape |
|---- | ---- | ---- | ---- |
| 1 | 1,C,H,W | N (>=1) | 1,C,H,W |
